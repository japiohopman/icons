# Icons — Product Roadmap

## Product vision

`icons` is a standalone application for creating, editing, managing, and exporting icon assets.

The application should own its user experience and workflows while using specialized engines where they provide value.

Photopea is one such engine. It should provide image-editing capabilities through its API and scripting interface while the Icons application owns the UI.
